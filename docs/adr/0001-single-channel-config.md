# ADR 0001: одна колонка `config` в `user_channel_configs`

## Контекст

Legacy-схема хранила канал в `channels` (12 колонок) плюс отдельные зашифрованные поля.
Для v2 нужна расширяемая схема без миграций на каждый канал.

## Решение

- `user_channels` — идентичность канала (`user_id`, `channel_type`, `enabled`).
- `user_channel_configs.config` — единственная колонка с JSON-настройками.
- С MasterKey значение хранится как `$mk$`-шифротекст; без MasterKey — как есть.
- Режим определяется по префиксу `$mk$`, отдельные `secret_ciphertext`/`key_version` не нужны.

## Последствия

- `channel_type` остаётся `VARCHAR`; справочник можно добавить позже.
- Все каналы читают/пишут один формат; расширение — без DDL.
- Шифрование/дешифрование выполняется в Go (`pkg/crypto`), не в SQL.
